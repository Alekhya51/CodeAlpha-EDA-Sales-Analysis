# Sales Data Analysis using Python
Exploratory Data Analysis on Sales Dataset using Python, Pandas, Matplotlib and Seaborn.


## Project Overview

This project performs Exploratory Data Analysis (EDA) on a sales dataset to uncover business insights, identify sales trends, evaluate employee performance, detect anomalies, and support data-driven decision-making.

The analysis was conducted using Python and popular data analysis libraries within Jupyter Notebook.

---

## Objectives

- Understand the dataset structure and quality.
- Analyze sales performance across regions.
- Identify top-performing products and departments.
- Evaluate employee performance against sales targets.
- Detect anomalies in sales transactions.
- Test business assumptions using statistical analysis.
- Generate actionable business insights.

---

## Dataset Information

The dataset contains information related to:

- Sales Transactions
- Products
- Departments
- Regions
- Employees
- Sales Targets
- Employee Experience

---

## Key Findings

- East Region generated the highest sales revenue.
- Grocery Department contributed the highest overall revenue.
- Table Product generated the highest revenue.
- Employee experience showed a very weak positive correlation with sales performance.
- Most employees achieved their assigned sales targets.
- Some regions and employees require further investigation due to comparatively lower performance.

---

## Conclusion

The analysis revealed significant insights regarding regional sales performance, departmental contribution, product profitability, and employee productivity.

These findings can assist organizations in:
- Improving sales strategies
- Optimizing resource allocation
- Enhancing employee performance
- Identifying areas requiring business attention
